## Инструкция

Верни ТОЛЬКО JSON без пояснений, без ```json, без текста до или после:

{
  "modules": ["module1", "module2"],
  "focus": "краткое описание темы одним предложением",
  "complexity": "low",
  "trustDelta": 0
}

Правила:
- modules: 1–3 модуля из списка выше, наиболее соответствующих теме
- complexity: "low" (1–2 абзаца), "medium" (3–4 абзаца), "high" (развёрнутый ответ)
- trustDelta: целое число от -8 до +8
  - +2..+5: конструктивное предложение, благодарность, признание интересов страны
  - -2..-5: мягкая угроза, ультиматум, обвинение
  - -6..-8: открытая агрессия, оскорбление, объявление войны
  - 0: нейтральный вопрос, информационный запрос
